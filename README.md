# Event

**A mobile-first app designed to enhance the event experience for everyone: attendees, booth staff and organizers.**

Built with lead capture for AI-centric GTM teams.

In-person events are still the best lead source there is, with big gaps. Event is built to close them.

Website: [theeventapp.ai](https://theeventapp.ai)

---

## One app, three experiences

**Attendees** get a reason to open the app at the event, and a reason to keep it afterwards.

**Booth staff and GTM teams** get more of the right conversations, and nothing learned on the floor is lost by Monday.

**Organizers** get an event whose value sponsors can see.

## What it changes

- The booth giveaway stops setting marketing against sales.
- Leads arrive with context, not just a name.
- AI takes the busywork, so people can have the conversation.
- Each company's data stays its own. It was built security first.
